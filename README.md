# 🧵 One District One Product – Power BI Dashboard

This project presents an in-depth Power BI dashboard analyzing India's **One District One Product (ODOP)** initiative, showcasing data on products, states, sectors, and GI tagging.

---

## 📌 Project Overview

The Government of India's ODOP scheme promotes unique, locally produced items from each district to drive economic growth. This dashboard is designed to assist policymakers, researchers, and citizens in exploring:

- Geographical product distribution
- Sectoral trends
- GI (Geographical Indication) status
- Category-wise classification (Primary, Secondary, Tertiary)

---

## 📊 Key Insights

- **Total Products**: 835  
- **Total Districts**: 779  
- **States & UTs Covered**: 36  
- **GI-tagged Products**: 256 (20.7%)  
- **Categories**: Primary, Secondary, Tertiary  
- **Top Sectors**: Agriculture, Handicraft, Manufacturing
